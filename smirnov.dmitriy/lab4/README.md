# Лабораторная работа 4

## Задание

Вариант 32. Создать приложение для работы с мероприятиями. Реализовать класс
`event`, методы работы с участниками, функции группировки и поиска мероприятий,
а также пользовательский интерфейс.

## Реализация

В `model.js` находятся класс `event` и функции группировки и поиска. В `main.js`
реализован интерфейс для создания и удаления мероприятий, добавления и удаления
участников, поиска по участнику и фильтрации по месяцу. На странице также
отображаются уникальные участники и группировки по дате и количеству участников.
Изменения выполняются асинхронно через `Promise` и `setTimeout`. Данные
сохраняются в `localStorage`.

## Запуск

Из корня репозитория выполни `npx serve .` и открой адрес, который покажет
команда. Перейди в папку `smirnov.dmitriy/lab4/`. Также подойдёт расширение Live
Server в VS Code.
